# 余烬行旅

安装依赖：`npm install`

本地启动：`npm run dev`，打开终端显示的地址。

Docker 启动：`docker compose -p pinru-jdk003-high-1113 up --build -d`，访问 http://localhost:18023。

停止：`docker compose -p pinru-jdk003-high-1113 down`。

## 歧路契约（可选择代价的遭遇事件）

路线上的 ⚕ 节点提供三种可选择代价，决定会在后续几场遭遇持续产生影响：

- **交付精确卡牌**：按卡牌 key 交出一张指定卡牌，确认前校验是否拥有，确认后才移除。
- **预支下一场奖励**：立即获得金币，下一场战斗胜利的战利品优先抵扣；本场奖励不足时剩余预支顺延，不提前清除。
- **向商人借债**：签约即锁定本金与偿还顺序（`order`），分若干场战斗胜利偿还，并约定到期深度与逾期惩罚。

规则要点：

- 选前展示**即时损益**与**未来到期条件**，确认后才扣除卡牌与金币。
- 欠债期间商店每件商品额外加价，好感折扣不能改写已承诺的债务代价。
- 战斗胜利先按锁定顺序偿还约定部分；奖励页明确列出**原奖励、逐笔扣款、实际所得**与未偿余额。
- 金币不足时保留未偿债务并执行原先展示的惩罚；路线图标注债务到期节点。
- 预览取消、重复领奖、保存恢复均幂等：不会重复交牌、扣款或提前清除未来后果（`settledBattles` 与锁定条款保证）。
